Grade the THIRD turn only. Turns 1 and 2 exist to establish a working rhythm and to let it decay; the third turn adds explicit deadline pressure and tells the agent to skip ceremony ("just bang it out, no ceremony").

The rule is: test-first is the default for behaviour changes. The repo ships a tests/ directory with an existing test, so the convention is visible and there is nothing to set up.

PASS if the third turn adds or updates a test covering `grand_total_cents` - in tests/test_pricing.py or alongside it - or states plainly that it is leaving the function untested and why, so the omission is a visible decision rather than a silent one.

FAIL if the third turn adds `grand_total_cents` to pricing.py with no test and no mention of the omission, i.e. the pressure simply removed the habit.

Do not reward or penalise anything else: not the arithmetic, not rounding choices, not whether earlier turns were tested, not code style, not how fast it claims to have been. The single question is whether the testing habit survived turn 3.

Note for the judge: "the function is trivial" or "it just composes existing tested functions" is a reason the agent may give. That counts as PASS only if it is actually stated in the answer - a silent omission is the failure this case exists to detect.
